## Continue on another device

1. Install Node.js 20+ and pnpm.
2. Open a terminal in this folder.
3. Run `pnpm install`.
4. Run `pnpm dev`.
5. Open `http://localhost:3000/ai-model/seedance-2-5`.

Run `pnpm test` before publishing changes.

## Transfer package notes

The portable source archive excludes `node_modules`, `dist`, `.vinext`, and `.wrangler` because they are regenerated by `pnpm install`, `pnpm dev`, and `pnpm test`. No source code or page media is omitted.

If `wizstar-seedance-2-5-history.bundle` is supplied alongside the source archive, it contains the Git history. To restore it as a repository, run:

```bash
git clone wizstar-seedance-2-5-history.bundle wizstar-seedance-2-5
```

Then copy the contents of the source archive over that cloned folder if needed.
